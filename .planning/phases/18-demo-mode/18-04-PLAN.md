### A. Accessibility bypass (useGameState.ts)

1. Read `client/src/hooks/useGameState.ts`. Locate `isDepartmentAccessible(roomId, completedRooms)` (lines 79-82).

2. Modify it to short-circuit when demo mode is active:
   ```typescript
   import { isDemoActive, DEMO_ROOM_ORDER } from '@/lib/demoSession';
   
   export function isDepartmentAccessible(roomId: string, completedRooms: string[]): boolean {
     if (isDemoActive()) {
       // Demo bypass: hospital_entrance + the 4 demo rooms are all accessible.
       // Hallways: also allow demo-room hallways (hallway_*) so the player can physically traverse between curated rooms.
       if (roomId === 'hospital_entrance') return true;
       if ((DEMO_ROOM_ORDER as readonly string[]).includes(roomId)) return true;
       // Hallways between demo rooms — allow them so navigation isn't blocked.
       if (roomId.startsWith('hallway_')) return true;
       // Anything else (e.g., lab, it_office) is NOT in the curated demo path — keep it locked.
       return false;
     }
     // Full-game path — unchanged.
     if (completedRooms.includes(roomId)) return true;
     return isDepartmentUnlocked(roomId, completedRooms);
   }
   ```

### D. ESC-to-start-menu (UnifiedGamePage.tsx)

8. Add a global keydown listener that fires when demo is active and pageMode === 'exploration':
   ```typescript
   useEffect(() => {
     if (!isDemoActive()) return;
     const handleEsc = (e: KeyboardEvent) => {
       if (e.key !== 'Escape') return;
       // Only fire from exploration mode — NOT during dialogue, encounter, etc.
       if (pageMode !== 'exploration') return;
       endDemo();
       setPageMode('start-menu');
       // Reset any in-page state that would carry over to a re-entry: encounter phase, modals, etc.
       setEncounterPhase('idle');
       setEncounterResult(null);
       setNarrativeCardData(null);
       setShowStoryModal(false);
       setSelectedItem(null);
       sceneStartedRef.current = false;                     // Allow Phaser scene to re-init on next demo entry
     };
     window.addEventListener('keydown', handleEsc);
     return () => window.removeEventListener('keydown', handleEsc);
   }, [pageMode]);
   ```

9. **Important:** When the player returns to start menu, the `gameState` hook STILL holds residual state from the demo session (completedRooms array may have new entries, etc). Because the persistence write is skipped during demo, those won't hit localStorage — but the in-memory `gameState.state` will still show "demo progress" if the player picks DEMO again. Two options:
   - (Simpler) Force a full reload on demo exit: `window.location.reload()`. The next page load will hit StartMenu fresh and useGameState will rehydrate from the unchanged save. **Recommended for Plan 04.**
   - (Cleaner) Add a `gameState.resetToSave()` function. More code, more testing.
   
   Use the reload approach: simple, deterministic, and matches how `handleNewGame` and `handlePlayAgain` already work in this file (lines ~844-857).
