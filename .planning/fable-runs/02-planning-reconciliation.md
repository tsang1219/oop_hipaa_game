**Mode:** docs only (no code changes) · **My checkpoint:** I read the two output docs

## The wish

contradict each other and the code. Read all of it, then figure out what's actually
**true of the game today**.

Give me:
- **One honest status doc** — what really exists and works right now, cutting through the
  stale planning cruft.
- **One concrete release checklist** — the real, checkable items left before I can ship
  next month. No fluff, no "consider maybe." If it's not a real task, it's not on the list.
- While you're in there, call out the **scariest tech-debt and risk hotspots**.

## Protect
- Docs only. Change no game code.
- Don't delete the old planning docs — mark them stale or archive them so history survives.

## Hand back
- `STATE_OF_TRUTH.md` — what's real now.
- `RELEASE_CHECKLIST.md` — ordered, concrete, checkable.
- A flag on every place a doc claimed something the code doesn't actually do.

Explore freely. When docs and code disagree, trust the code.
